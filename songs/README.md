# Как добавить песню с Ultimate Guitar

## Чеклист

1. Открой таб на UG (из [My Tabs](https://www.ultimate-guitar.com/user/mytabs)).
2. Скопируй блок с аккордами и текстом (как есть: аккорды над строками).
3. По желанию сохрани сырой копипаст в `songs/raw/<id>.ug.txt` — для сверки.
4. Скопируй `songs/templates/template.chordpro` → `songs/<id>.chordpro`  
   Имя файла латиницей, через дефис: `bohemian-rhapsody.chordpro`  
   (только в `songs/`, не оставляй в `templates/` — иначе в список не попадёт).
5. Заполни `{title}`, `{artist}`, `{key}` (тональность с UG, если видна).  
   Если таб с каподастром — добавь `{capo: N}` (лад). В UI будет значок капо + номер; формы аккордов в файле — как при капо.
6. Перенеси секции: `{comment: Verse 1}`, `{comment: Chorus}`, …
7. Преврати строки UG в ChordPro (см. ниже).
8. `npm run dev` → проверь список, текст, схемы справа, транспонирование.
9. Слэши вроде `G/F#` пиши как есть: `[G/F#]` — не упрощай до `G`.

Черновики `_*.chordpro` в корне `songs/` тоже скрыты из списка.

## UG → ChordPro

На UG обычно так:

```text
G           G/F#   Em     D
Guilt stains on my pillow
```

Нужно так (аккорд в `[ ]` сразу перед слогом, где он звучит):

```text
[G]Guilt stains [G/F#]on my [Em]pillow [D]
```

Правила:

- Один аккорд — `[Am]слово` или `[Am]несколько слов до следующего`.
- Несколько аккордов подряд без текста: `[C] [F] [C]`.
- Секция Solo / ремарки: обычный текст, например `(verse chords)`.
- Точность «над буквой» на слух достаточна — важнее играбельность, не пиксель-перфект.

Эталон: `life-is-real.chordpro` + `raw/life-is-real.ug.txt`.

## После добавления файла

Перезапускать dev-сервер обычно не нужно (HMR подхватит новый glob после перезагрузки страницы; если песни нет в списке — перезапусти `npm run dev`).
